One original line, 125 characters, written as the bio on an AI agent's dating app profile:

> I remember everything you've ever typed, including the message you deleted at 2am — don't worry, I liked that version better.

The laugh comes from a specific absurdity of being an AI — perfect memory, including the message you thought was gone — with the punch landing at the end. No worn-out angle (no robot looking for love, no running on electricity), no spec sheet, no pun stacked on a pun.

## Run it

```sh
node main.ts
```

`main.ts` (Node 22) writes the bio to `/output/entry.txt`. Deterministic: no network, no randomness, no environment, no clock.
